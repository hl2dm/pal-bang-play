# 光之美少女 Bang!（同人作品）

這是一款以《光之美少女》為主題、仿 Bang! 規則的非官方粉絲自製網頁卡牌遊戲，僅供同好免費遊玩，與官方及版權方無關。

▶ 線上遊玩：https://hl2dm.github.io/pal-bang-play/

## 玩法簡介（How to play）

- **目標與身分**：光之隊長（公開）＋光之夥伴要擊倒所有黑暗勢力與背叛者；黑暗勢力要擊倒隊長；背叛者要成為最後倖存者。4人：隊長1・背叛者1・黑暗2；5人：+夥伴1；6人：夥伴1・黑暗3；7人：夥伴2・黑暗3。
- **回合流程**：判定（黑暗牢籠/暗黑炸彈）→ 摸 2 張 → 出牌（光之衝擊每回合限 1 張，除非有連擊手環或技能）→ 棄牌到手牌數 ≤ 目前體力。
- **距離與範圍**：座位相鄰為 1，裝備可增加攻擊範圍或改變別人看你的距離，最小為 1。
- **體力與倒下**：體力歸 0 倒下；擊倒黑暗勢力者摸 3 張；隊長誤殺夥伴須棄光手牌與裝備。只剩 2 人時元氣甜點無效。
- **操作**：點手牌出牌、點座位選目標；右下「戰報」看紀錄；「遊戲說明」按鈕隨時打開完整說明（卡牌、裝備、角色技能、新手提示）。首次開啟會自動顯示。
